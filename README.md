# สมุดทริปญี่ปุ่น (旅のしおり)

เว็บวางแผนเที่ยวญี่ปุ่นแบบไฟล์เดียว เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

- **แผนรายวัน** สร้างวันอัตโนมัติจากวันเดินทาง เพิ่มกิจกรรม เวลา โน้ต ค่าใช้จ่าย และลิงก์ Google Maps
- **งบประมาณ** รวมค่าใช้จ่ายจากแผนและรายการอื่น (ตั๋ว ที่พัก) แยกหมวด เทียบงบ แปลงเยน/บาท
- **เช็กลิสต์** ของที่ต้องเตรียมก่อนไปญี่ปุ่น เพิ่มเองได้
- **ไอเดียที่เที่ยว** สถานที่ยอดนิยม 7 ภูมิภาค กดเพิ่มลงแผนได้ทันที และประโยคญี่ปุ่นที่ใช้บ่อย
- คำแนะนำตามฤดูกาลของเดือนที่เดินทาง และนับถอยหลังวันออกเดินทาง

ข้อมูลบันทึกใน localStorage ของเบราว์เซอร์ ย้ายเครื่องได้ด้วยปุ่ม "คัดลอกข้อมูลทริป (JSON)" แล้วนำเข้าที่เครื่องใหม่
