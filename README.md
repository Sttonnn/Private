# ไปดูฟูจิหน้าหนาว (12–17 ม.ค. 2027)

เว็บไกด์ทริปฟูจิ + โตเกียว 2 คน แบบไฟล์เดียว เปิด `index.html` ในเบราว์เซอร์ได้เลย

- **แผนเที่ยวรายวัน** ไทม์ไลน์ทุกวัน ทุกจุดมีปุ่มนำทาง ปุ่มเปิด Google Maps และแผนที่ฝังในหน้า พร้อมลิงก์เส้นทางทั้งวัน
- **ตั๋วและที่พัก** ZIPAIR ZG52 / ZG51, Fujikawaguchiko Resort Hotel (ที่อยู่ภาษาญี่ปุ่นสำหรับแท็กซี่) และสิ่งที่ยังต้องจอง
- **ที่เที่ยวเพิ่มเติม** กรองตาม ธรรมชาติ / กินดื่ม / สัตว์ / พักผ่อน
- **เตรียมตัว** อากาศ การแต่งตัว เช็กลิสต์ (บันทึกในเบราว์เซอร์) ประโยคญี่ปุ่น เบอร์ฉุกเฉิน
